# Camila y Lizy

Juego de carreras con Camila y Lizy, las perritas de la familia: saltar limoneros y árboles de mango, agacharse cuando pasa el cuculí y juntar huesos y marraquetas.

Jugar: https://abgdanielm.github.io/Juego-Lizzy-y-Camila/

Controles: barra espaciadora o flecha arriba para saltar (doble salto), flecha abajo para agacharse, P para pausa. En el celular, botones en pantalla.
